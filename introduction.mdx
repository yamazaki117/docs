## Welcome to Visare for Cl@ve

Visare provides a third-party OAuth2/OIDC implementation for the Spanish Cl@ve authentication system. As official OIDC integration is not yet available from Cl@ve, our solution bridges this gap by offering standards-based authentication flows compatible with modern application architectures.



Ready to integrate with Spain's Cl@ve system? Start with our [Quick Start Guide](/quickstart)
